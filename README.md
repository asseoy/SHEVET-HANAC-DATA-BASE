# שבט הנשיא — הארכיון V3

אתר סטטי מלא ב-HTML/CSS/JavaScript, ללא תלות ב-Drive בזמן הצפייה.

## פתיחה מקומית ב-Windows / ASUS
1. חלצו את קובץ ה-ZIP: קליק ימני > Extract All.
2. פתחו את התיקייה שחולצה.
3. לחצו פעמיים על `index.html`.

## פרסום פשוט ב-Netlify
1. היכנסו ל-Netlify Drop.
2. גררו את כל התיקייה `shevet-hanassi-site` (לא את ה-ZIP) לאזור ההעלאה.
3. Netlify ייתן כתובת ציבורית לאתר.

## קבצים
- index.html — מבנה האתר
- style.css — העיצוב והרספונסיביות
- app.js — כל הנתונים, הסינון והמשחקים
- assets/ — סמלי השבט המקומיים באתר

## מה יש בגרסה הזו
- שכבות מ-1967 עד 2030 לפי המסמך במאגר
- חיות שכבה מתועדות
- עובדות היסטוריות
- מסורות
- מאגר הפעלות לדוגמה
- משחקים: חיה, שנת סיום, זיהוי שכבה, אמת/חרטא
- מבנה כל עולמות המאגר
- סמלי שבט מקומיים, ללא מעבר ל-Drive

האתר אינו פונה ל-Google Drive בזמן שימוש רגיל.
